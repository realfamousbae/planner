# Security policy

Planner is an instruction package with a local Python installer. It has no
hosted backend and needs no API credentials. The agent and host retain their
normal permissions; a plan must not be treated as permission to override them.

For suspected credential exposure, unsafe installation behavior, or a workflow
that bypasses approval boundaries, use [GitHub private vulnerability reporting](https://github.com/realfamousbae/planner/security/advisories/new).
If private reporting is unavailable, open a minimal issue requesting a private
contact without publishing exploit details or sensitive data.

Include affected revision, host/version, steps to reproduce, and impact using
sanitized examples. Do not send secrets or private repository transcripts.
Only the current main branch is maintained at this stage; no response-time
guarantee is offered.
