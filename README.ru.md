# Planner

[English](README.md) · [Русский](README.ru.md)

[![Проверки](https://github.com/realfamousbae/planner/actions/workflows/checks.yml/badge.svg)](https://github.com/realfamousbae/planner/actions/workflows/checks.yml)

**Продумать изменения. Передать план. Реализовать в новой сессии.**

Planner — переносимый Agent Skill для Codex, Claude Code и совместимых агентов.
В первой сессии агент изучает репозиторий, обсуждает решения и готовит план.
Во второй другая модель выполняет этот план и обновляет прогресс.
Весь контекст задачи хранится в одном `PLANNER.md` в корне репозитория.

Стартовый профиль — **Sol / high → Terra / medium**. Его можно изменить.
Если эти модели недоступны, скилл предлагает аналоги и согласует выбор.
Экономия и качество пока не измерены сравнительными испытаниями.

## Установка

Выберите удобный способ. **Установка скилла не добавляет встроенный Plan Mode
и доступ к репозиторию** — для полного процесса нужны обе возможности.
Успешная загрузка в обычный чат сама по себе не подтверждает совместимость.

| Способ | Где | Что нужно |
| --- | --- | --- |
| Попросить агента установить | Приложение Codex, CLI, IDE; Claude Code | Доступ агента к локальным файлам и GitHub |
| Python-установщик | Codex и/или Claude Code | Python 3.9+; Git или скачанный ZIP репозитория |
| Скопировать папку вручную | Для всех проектов или одного репозитория | Файловый менеджер; Python и Git не нужны |
| Загрузить ZIP скилла | Настройки скиллов Claude web/Desktop | Разрешённая загрузка; совместимость процесса проверяется отдельно |
| Штатный установщик другой среды | Другие агенты с Agent Skills | Встроенный Plan Mode и доступ к репозиторию |

Сам скилл состоит из Markdown и YAML, не требует API-ключей и зависимостей
для исполнения. Это альтернативные способы: достаточно одной установки на агент.

### 1. Через диалог с агентом

В **приложении Codex** откройте сессию для работы с кодом с доступом к локальным
файлам и отправьте:

```text
$skill-installer установи скилл из https://github.com/realfamousbae/planner/tree/main/skills/planner
```

Это сообщение агенту в GUI, а не команда терминала. Такой же запрос можно
использовать в Codex CLI и расширении IDE при наличии встроенного skill-installer.
Если его нет, используйте Python-установщик или ручное копирование.
[Официальная инструкция Codex](https://learn.chatgpt.com/docs/build-skills).

В **Claude Code**, в том числе в сессии Code приложения с доступом к локальным
файлам, можно попросить агента выполнить ручную установку:

```text
Установи Planner из https://github.com/realfamousbae/planner/tree/main/skills/planner
в мой пользовательский каталог скиллов. Скопируй папку целиком, включая references,
assets, agents и LICENSE. Добавь disable-model-invocation: true в YAML-заголовок
SKILL.md. Существующую установку не заменяй; сообщи путь установки.
```

Это просьба агенту установить файлы, а не встроенная команда Claude.
Проверьте получившийся путь. Для неё нужен доступ на запись к локальным файлам;
наличие такого доступа у обычного облачного чата не предполагается.

### 2. Python-установщик

Клонируйте репозиторий, проверьте содержимое и запустите:

```sh
git clone https://github.com/realfamousbae/planner.git
cd planner
python3 scripts/install.py --dry-run
python3 scripts/install.py
```

Без Git откройте [страницу репозитория](https://github.com/realfamousbae/planner),
выберите **Code → Download ZIP**, распакуйте архив и откройте терминал в
распакованной папке. Затем выполните две команды Python.
На Windows вместо `python3` может использоваться команда `py`.

Установщик определяет `codex` и `claude` по PATH. При необходимости выберите
агента явно, в том числе если CLI приложения не добавлен в PATH:

```sh
python3 scripts/install.py --agent codex
python3 scripts/install.py --agent claude
python3 scripts/install.py --agent both
```

Это альтернативные варианты выбора. Установщик создаёт отдельные копии
по пользовательским путям ниже и сам добавляет настройку явного вызова Claude.
Существующие каталоги, сломанные символические ссылки и старая установка Codex
в `~/.codex/skills/planner` сохраняются: установщик откажется их заменять.

### 3. Ручное копирование: для пользователя или проекта

Скачайте и распакуйте ZIP репозитория либо клонируйте его. Скопируйте
**всю папку** `skills/planner`, а не только SKILL.md, в один из каталогов:

| Агент | Для всех ваших проектов | Только для одного репозитория |
| --- | --- | --- |
| Codex | `~/.agents/skills/planner` | `<репозиторий>/.agents/skills/planner` |
| Claude Code | `~/.claude/skills/planner` | `<репозиторий>/.claude/skills/planner` |

`~` — домашняя папка пользователя. На Windows соответствующие пути начинаются
с `%USERPROFILE%`, например `%USERPROFILE%\.agents\skills\planner`.
Создайте недостающие родительские папки. В Finder на macOS открыть скрытый
каталог можно через **Переход → Переход к папке** (`Cmd+Shift+G`); в Проводнике
Windows вставьте путь в адресную строку.

При ручной установке в **Claude Code** добавьте внутрь существующего YAML-заголовка
в начале SKILL.md:

```yaml
disable-model-invocation: true
```

Codex использует уже включённый `agents/openai.yaml` для явного вызова.
Не устанавливайте одновременно пользовательскую и проектную копии для одного агента.
[Документация скиллов Claude Code](https://code.claude.com/docs/en/skills).

### 4. Claude web/Desktop: загрузка ZIP через GUI

В Claude есть загрузка пользовательских скиллов через
**Customize → Skills → + → Create skill → Upload a skill**.
Должно быть включено выполнение кода и создание файлов; настройки организации
могут ограничивать загрузку.
[Официальная инструкция Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude).

Подготовка архива через файловый менеджер:

1. Скачайте и распакуйте репозиторий.
2. Внутри `skills` сожмите папку `planner` в `planner.zip`.
3. Убедитесь, что внутри ZIP находятся `planner/SKILL.md` и соседние папки ресурсов.
4. Загрузите этот ZIP в Claude и включите скилл.

Не загружайте целиком исходный архив GitHub как скилл. Готовый ZIP для загрузки
пока не опубликован. Здесь описан общий механизм Claude; **загрузка и выполнение
Planner в чате Claude web/Desktop пока не проверены**. Для загруженных скиллов
могут отличаться метаданные и способы вызова от локального Claude Code.
Не рассчитывайте, что `/planner` работает в обычном чате.
Для полного процесса Planner по-прежнему нужны встроенный Plan Mode и доступ
к репозиторию — используйте совместимую сессию для работы с кодом.
Одна загрузка совместимость не подтверждает.

### 5. Другие совместимые агенты

Установите общую папку `skills/planner` через механизм, описанный в документации
вашего агента. Нужны встроенный Plan Mode и доступ к репозиторию.
Если доступна настройка запуска только по явному запросу, включите её;
инструкции скилла также требуют явного запуска.
Команды Codex/Claude и названия моделей не обязательно применимы в других средах.

### Проверка, обновление и удаление

После установки откройте новую сессию и проверьте наличие Planner в списке
скиллов. Если его нет, проверьте путь, вложенность папок и поддержку способа
установки в вашем клиенте. Полный интерактивный прогон пока не проводился;
локальные тесты установки проверяют Python-установщик.

Установленные локальные копии не обновляются автоматически. Для обновления
проверьте старую копию, удалите или перенесите её, получите свежие исходники
и повторите установку выбранным способом. Сначала сохраните собственные правки.
Для удаления локального скилла удалите только его папку `planner`.
Загруженный скилл Claude можно отключить или удалить в Customize → Skills.
Удаление скилла не удаляет планы задач из репозиториев.

## 1. Планирование

Выберите модель для планирования, включите **встроенный Plan Mode** и отправьте:

```text
# Codex
$planner plan Добавить пагинацию в ленту активности.

# Claude Code
/planner plan Добавить пагинацию в ленту активности.
```

Скилл спросит effort (по умолчанию high), изучит код и задаст вопросы.
Затем предложит план и модель для реализации. Утвердите итоговую версию,
выйдите из Plan Mode и в той же сессии отправьте:

```text
Сохрани утверждённый план в PLANNER.md. Реализацию не начинай.
```

Пока режим запрещает запись, план остаётся в переписке. Скилл должен
подтвердить сохранение файла перед передачей задачи в новую сессию.
Если у агента нет встроенного Plan Mode, планирование не запускается.

## 2. Реализация

Откройте новую сессию в том же репозитории/worktree, выберите рекомендованную
модель и отключите Plan Mode:

```text
# Codex
$planner implement

# Claude Code
/planner implement
```

Дополнительные инструкции можно дописать после режима:

```text
$planner implement Используй high effort. Сохрани совместимость существующего API.
```

Агент прочитает план, согласует effort и проверит актуальность относительно
кода. При отсутствии доступного управления настройками попросит переключить
их вручную. Он не выдаёт выбранные настройки за подтверждённые и не меняет
глобальные предпочтения.

Технические детали агент решает самостоятельно. Изменения цели, архитектуры,
публичных интерфейсов и объёма обсуждает с пользователем. Этапы, реальные
результаты проверок и следующий шаг записывает в `PLANNER.md`.
После прерывания можно открыть ещё одну сессию с `implement`.

Один файл хранит одну задачу. Незавершённая задача не заменяется без обсуждения;
завершённый план заменяется после утверждения следующего. Архивов нет.
Инструкции скилла написаны на английском, а общение и планы следуют языку пользователя.
